# Alpha Physics - Admin App (APK)
1. GitHub එකේ new repo එකක් හදලා මේ folder එකේ files ඔක්කොම upload කරන්න (.github folder එකත් ඇතුළුව).
2. Repo > Actions > "Build APK" > Run workflow (විනාඩි 3-5).
3. Run එක ඉවර වුණාම පහළ "Artifacts" > Alpha-Admin-APK download කරන්න (zip එක ඇතුළේ app-debug.apk).
4. Phone එකට install කරන්න (Unknown sources allow කරන්න).
